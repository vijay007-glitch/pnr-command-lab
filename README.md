# PnR Command Lab

Type Innovus-style TCL commands and watch a gate-level Verilog netlist become a placed, clocked and routed layout.

- Live: https://vijay007-glitch.github.io/pnr-command-lab/
- Write-up: https://vijay007-glitch.github.io/posts/pnr-command-lab/

## Run it

It is one self-contained page, so open `index.html` in a browser. Or serve the folder:

```
python -m http.server 8000
```

The page loads web fonts from Google Fonts, so it needs a network connection for the intended typefaces.
